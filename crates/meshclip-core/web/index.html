手机 → Windows

每个文件最多 64 MiB；先发送请求，Windows 接受后点击“开始 / 继续”。刷新后保留任务，可重新选择同一文件续传。最终由 Windows 校验 SHA-256。

Windows → 手机

只列出 Windows 明确选中共享的文件。下载前验证 SHA-256，浏览器可能在确认下载后再次提示保存。

    扫描二维码使用手机系统相机或扫码工具。首次连接使用临时自签名 HTTPS 证书，请通过 Windows 显示的 SHA-256 指纹核对证书；不确定时停止访问。若浏览器限制剪切板 API，请在文本框中长按粘贴或选择复制。关闭网页、锁屏或切换应用可能中断传输。关闭 Windows 的网页共享后，所有会话失效。
